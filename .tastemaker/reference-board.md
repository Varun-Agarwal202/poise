# Poise reference board

## Product read

- Audience: daily puzzle players who enjoy compact, skill-based games.
- Job: place a pin precisely, understand the result immediately, and return tomorrow.
- Mode: operate. The interface should feel like a small precision instrument.
- Density: low visual noise with a concentrated play field.

## Reference field

### Minute Cryptic

- Useful trait: one clear daily task, confident editorial type, and visible edition metadata.
- Poise translation: make the daily number and the five-object set feel like a printed issue.

### CodePop

- Useful trait: tactile interaction in a clean browser game with almost no surrounding chrome.
- Poise translation: keep the balance object as the visual anchor and make controls feel physical.

### New York Times Games

- Useful trait: repeatable daily ritual, restrained navigation, and results designed for sharing.
- Poise translation: preserve the simple daily loop and make the final score read like a keepsake.

## Chosen direction

Precision instrument plus printed calibration slip. Warm paper replaces neutral app gray. Copper identifies the player's pin. Teal identifies the true balance point. Fine measurement lines, compact corner labels, and squared controls create a consistent authored system.

## Rejected directions

- Neon arcade: fights the quiet concentration of the game.
- Soft pastel wellness app: weakens the sense of accuracy and skill.
- Heavy skeuomorphism: competes with the generated physical objects.
- Generic card dashboard: adds containers without helping the play loop.

## Result references supplied by the user

### Krillion

- Useful trait: a full distribution curve with a clear vertical marker and direct comparative language.
- Poise translation: keep the curve quiet, but make the player's position unmistakable.

### Fermi

- Useful trait: a compact Top X% badge that communicates the result before the chart needs to be read.
- Poise translation: use a neutral high-contrast percentile pill above the curve.

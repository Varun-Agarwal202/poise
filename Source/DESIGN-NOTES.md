# Current design direction

The attached Impeccable skill was applied as a refinement, with the user's original uploaded UI as the reference. This replaces the earlier Taste Skill redesign direction.

Poise is a game: the object and interaction take priority. Preserve the large original title, expressive Bricolage Grotesque typography, charcoal/pale-gray palette and compact icon navigation. Remove repeated explanation and decorative badges rather than replacing the identity.

The important hierarchy is date/navigation → Poise and the rule → the physical object → today's five and one Play action. During play, prioritize the object, score progress, materials and Drop pin. At reveal, make accuracy legible through the pin, target and error line, with truthful feedback. Use the same results page as the copied image; omit navigation and actions from the image. One Copy button replaces the entire sharing modal.

The refined version keeps daily scarcity, varied authored shapes, an honest skill signal, a completion record and a shareable image. These provide reasons to return without adding endless practice, arbitrary rewards or more interface clutter.

The home layout uses the available window width: two columns on laptop/panel widths from 640px and one on narrow phones. A manual layout preference is available in Settings. The header spans the page, while the object has its own large stage beside the title and daily action.
